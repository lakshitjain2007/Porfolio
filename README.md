# Lakshit Jain — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — portfolio structure/content
- `style.css` — responsive design and animations
- `script.js` — navigation, theme toggle and reveal animations
- `assets/profile.jpg` — profile photo

## GitHub Pages

1. Create a new GitHub repository, e.g. `portfolio`.
2. Upload all files and the `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and open the generated GitHub Pages URL.
